# General Relativity

A VuePress documentation site scaffolded from the Phyz documentation framework.

The site uses KaTeX for mathematics and SlimSearch for search. Manim support
is available through scripts/render-manim-diagrams.mjs. The Feynman-diagram
pipeline is intentionally not included.

The main reading order contains ten chapters, from the equivalence principle to
gravitational waves. Six supporting chapters cover prerequisites, cosmology,
lensing, and experimental tests. The homepage and navigation share their
chapter metadata in docs/.vuepress/curriculum.js.
